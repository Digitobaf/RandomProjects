ABBY IN CASEY'S ROOM — WINDOWS

1. Extract the entire ZIP. Keep the updated Casey's Room HTML in its usual folder and use your usual browser/profile so your existing local saves remain accessible.
2. Double-click Start AIM.cmd. The first run installs Google's official Gemini SDK using Node.js.
3. Notepad opens an empty document. Paste ONLY your Gemini API key into it, then press Ctrl+S. The launcher detects the saved key automatically. Close Notepad when the launcher says Key saved. Your key is saved in aim-local/.env on your computer.
4. Keep the launcher window open. Casey's Room opens in your default browser at http://127.0.0.1:43187/. Use this page for Abby; the local service connects it automatically.
5. Open AOL Instant Messenger. Enter any screen name and choose Sign On; the AIM password field is unused. Cancel skips the connecting animation.
6. Select xXx_SoupSlut_xXx to talk to Abby. Enter sends a message; Shift+Enter adds a line. Book buddies such as Helga still transcribe ebooks as before.

If the browser asks whether Casey's Room can connect to your local network, allow it for the local AIM connection.

MOVING CASEY'S ROOM
Close the black launcher window before moving files. Move the entire app folder, including aim-local, so your local key and Abby profile come with it. Then run Start AIM.cmd from the new location. The launcher now uses a stable local web address, so its browser data stays at that address even when the folder moves. Data saved while opening the HTML directly remains at that old file location; open the old file to export any diary entries or other records you want to transfer. The first local-web launch can look like a fresh app. Book progress can be restarted. For mGBA, keep the game ROM and the JSON file from File -> Export All Saves. Restore that JSON through File -> Import Save Backup, then open the matching .gba game. An individual .sav export instead uses Import Game Save.

YOUR SAVES
Abby's messages and unfinished draft are stored in a separate browser database. Each completed AIM sign-in starts a fresh chat and archives the previous conversation and draft. Closing only the conversation window or minimizing AIM keeps the current session. Closing AIM, restarting the launcher, or a failed API call does not intentionally delete them. Keep using the same browser/profile and local web address. The old direct-file copy keeps its own browser data separately. Clearing site data or using a private browsing window can remove or isolate these saves.
Recent conversation is sent to Gemini with Abby's character instructions. Previous sessions are not sent to Gemini. There is no separate automatic long-term memory system; keep lasting character details in Edit Abby.

CHAT HISTORY
Open File -> Chat History in the AIM conversation window. Old sessions are read-only; reading one does not add it to the current conversation or send it to Gemini. The existing chat from before this update is preserved here on your first sign-in.
History stores text and small index records, without duplicating avatars, artwork, or sounds. Startup loads only the current thread. History lists 30 sessions at a time and displays up to 100 messages at a time. The window shows an approximate total size for saved chat text.
Use Export .txt to save a selected chat outside Firefox. Delete removes only that selected archive after confirmation. History is not automatically erased; export and delete old sessions when you no longer want them stored in the browser. Browser clearing or private browsing can still remove or isolate saved chats.

ABBY'S CHARACTER
Edit Abby.cmd opens her local character notes. Save the file; each new reply uses the latest saved notes without restarting. A reply already underway uses the notes saved when it started. Use Edit Abby.cmd from the same folder as Start AIM.cmd; the launcher prints the active profile path. Your local abby-profile.txt is preserved on future updates and excluded from Git and download ZIPs.

CHAT SCROLLING
New messages automatically scroll the conversation fully to the bottom after the text and smileys finish laying out. The view stays at the bottom through late layout and window-size changes. You can scroll up to read older messages between replies; the next new message brings the latest reply into view. The separate Chat History reader keeps its own scroll position.

REPLY STYLE AND TIMING
Abby defaults to brief instant messages, usually 1–3 sentences. Add conversational preferences to Edit Abby, such as: "Keep most replies to one or two sentences. Match my message length. Avoid long monologues or elaborate invented stories." Save to apply to the next message. Replies have a length-aware typing pause of about 2–6.5 seconds, including time Gemini already spent generating the reply. Longer generation times do not add another full pause. AIM shows Abby is typing while waiting. Warnings and the Retry button wrap within the status area without clipping.

SMILEYS
Abby uses classic text emoticons instead of modern Unicode emoji. Her incoming reactions are converted to old-school smileys before saving new replies; older saved originals stay intact and are displayed in the classic style. User messages and book passages are preserved.
In Abby chat, use the smiley face on the formatting toolbar to choose from 16 classic yellow smileys. You can navigate the picker with arrow keys and Enter, and close it with Escape. The face inserts at your cursor or replaces selected text. Messages store and send the plain-text emoticon, and display it as a yellow face in the chat. Book transcription keeps its original text and controls.

YOUR KEY
Do not enter the API key into AIM's chat or password field. To change the key, close the running launcher and use Set Gemini Key.cmd. Paste the new key into the empty Notepad document and press Ctrl+S. Do not type the key in the black window. Then start AIM again.
The Google key stays in the local service. The local web page connects automatically using a temporary local session token. It sends chat messages only to 127.0.0.1. It does not receive the Google key.
.env, local session files, and installed dependencies are excluded from version control and from the distributed ZIP.

CONNECTION TROUBLE
- Keep Start AIM.cmd open while chatting. For Abby, use the page at http://127.0.0.1:43187/ that the launcher opens. Opening the HTML directly does not connect Abby.
- Temporary Google server errors, connection interruptions, and timeouts are retried automatically, up to three attempts with brief pauses. The total recovery window stays under 48 seconds; Abby remains typing while it runs.
- If all attempts fail, the sent message remains visible. Choose Retry beside the error to ask for the reply again. A retry does not add another copy of your sent message.
- Persistent errors now distinguish Google server failures (including HTTP status), timeouts, DNS lookup failures, secure-connection failures, access problems, and quota limits. The black launcher window prints short diagnostic codes for retries and failures. It does not print your key, messages, or character notes.
- Quota, key/access, model, and invalid-request errors are not automatically retried. Check the displayed cause before choosing Retry.
- Free-tier limits can require waiting before retrying. There is no automatic switch to another model or to paid billing.
- The launcher prints the active model as Gemini model: .... AI Studio’s selected chat model is separate from AIM’s GEMINI_MODEL setting. The model now defaults to gemini-3.5-flash-lite. On the first launch after this update, AIM changes only GEMINI_MODEL in your local .env file to this model and keeps your key. This happens once; later manual model choices are respected. This version supports the model’s updated sampling-parameter requirements. Google documents a free tier for it, subject to your project’s limits. If Google reports that this model is unavailable for your project, select an available free-tier text model in AI Studio and change GEMINI_MODEL in aim-local/.env. Restart the launcher.
- If setup says Node.js is missing or too old, install the current LTS from https://nodejs.org/.
- Close any old AIM launcher window before replacing its files or changing the key.

PRIVACY
Gemini needs internet access. The unpaid API can use submitted content and responses for product improvement, including human review, subject to Google's applicable regional terms. Your messages are sent to Google only when you send or retry a chat message. No API subscription to Gemini Advanced is required.

VERIFICATION
The chat flow, storage, retry behavior, book-mode compatibility, and official SDK request format were tested with controlled responses. A live Google request requires your own key and project access on your computer. This build environment cannot run Windows .cmd files or open local file:// browser pages.

FREE QUICK FACT LOOKUPS
Abby can make one short Wikipedia topic lookup when a public fact may be outdated or you ask her to check it. The app uses the public Wikipedia API, not paid Google Search. No new key or account is needed. Regular Gemini free-tier message/token quotas still apply, including the extra reply step after a lookup.
This is basic encyclopedia fact-checking, not general web search or deep research. Lookup results stay behind the scenes; Abby replies normally without source links. If results are missing or unavailable, she is instructed to acknowledge uncertainty.
