# Casey’s Room

[Download Casey’s Room ZIP](https://raw.githubusercontent.com/Digitobaf/RandomProjects/main/Caseys-Room.zip)

Unzip the download and open **Caseys-Room-with-Mood-Ring.html** in your browser. The complete app, artwork, fonts, and sounds are included in that one HTML file.

This version includes Diary and Mood Ring, the painted **A Month in Jewels** calendar, the fairy swoosh when Mood Ring opens, and **Light Spell** when the ring stone changes color. Lamplight Write and Diary retain their existing code and behavior.

[View the HTML file](https://github.com/Digitobaf/RandomProjects/blob/main/Caseys-Room-with-Mood-Ring.html)
