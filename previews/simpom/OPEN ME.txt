SIMPOM — GAME UI UPDATE (v5)

1. Close SimPom.
2. Extract into your EXISTING v4 SimPom folder (with SimPom.html).
3. Replace included files, keep existing assets, and reopen SimPom.html.

New: curved blue game-style controls, green timer display, Play/Pause/Reset
icons, and a connected Buy Mode dock. Durations still edits your own times.

Buy Mode uses picture-only slots. Hover for the original object name,
price and description. Keyboard focus works too; Escape closes the preview.
The supplied selection sound plays before a running item's animation/audio.
Sound off skips the cue. While paused, select an item and press Start as usual.

All 95 items remain. Previous drink/steam/book changes and saves are retained.
This is separate from Casey's Room; no Start AIM launcher is needed.
See UI-NOTES.md and README-for-Pollux.md for the current shared workflow.
