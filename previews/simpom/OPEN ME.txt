SIMPOM — ANIMATION AND SOUND FIXES (v2)

UPDATE YOUR EXISTING SIMPOM FOLDER:
1. Close the SimPom tab.
2. Extract this update into the same folder that contains SimPom.html.
3. Replace the included files, keeping your existing assets folder.
4. Open SimPom.html again in Firefox.

This is a small update, not a complete new installation. It needs the
assets from the original all-100-picks SimPom-Mockup.zip. New installations:
extract that original ZIP first, then apply this update into that folder.

Do not extract into Casey's Room. No Start AIM launcher is needed.
Timer preferences keep the same storage key. Use the same folder/browser.
Nothing in Casey's Room, AIM, its private profiles or saves is changed.

All 100 picks remain. Start activates an object and its configured sounds;
click for its interaction. Buy Mode search and paging choose the object.
Objects start SE when selected. Poseidon's aquarium is NE/NW only.
Durations still lets you choose your own focus and break lengths.
Pause stops motion/audio; Resume continues the paused animation phase.
Reset returns to the starting appearance. Reload restores the clock paused.

Fireplace ignition now plays once, followed by a steady burning loop.
Water fills stay inside basins. Moving parts use original game sprites
against a fixed body, so enhanced textures no longer morph each frame.
The two requested beds and phone booth stay visually fixed with sounds.
Aquariums remain alive. The Porcina export has no stocked interior variant.

See ANIMATION-FIXES.md for all requested changes and README-for-Pollux.md
for the editable data format and shared update rules.
